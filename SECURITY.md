# Security

## Supported versions

Only the newest release of json-shaper-lite gets fixes.

## Report a problem

Please do not open a public issue for a security problem.

Use GitHub's private report form instead:
https://github.com/tidybytetools/json-shaper-lite/security/advisories/new

Tell us what you found and how to make it happen again. We will reply as soon as we can, and we will credit you if you want.

## What this tool does

json-shaper-lite runs on your own computer. It does not send your text or files anywhere. The MCP tools only read; they never write or change files. It has no accounts, no API keys and no tracking.
